# Sales-and-Product-Performance-Analytics-Dashboard-PowerBI
## Project Overview
This project focuses on analyzing transactional data to uncover sales trends, profitability insights, and product performance metrics. Built an interactive Power BI dashboard using SQL, DAX, and star-schema modeling to deliver actionable business insights. The dataset contains 5000+ transaction record. The goal of this project is to help stakeholders understand revenue drivers, identify profitable product categories, track business growth, and support data-driven decision-making.

## Business Overview
* Analyze overall sales and profitability performance.
* Identify top-performing products and categories.
* Monitor Year-over-Year (YoY) business growth.
* Discover seasonal sales trends and purchasing patterns.
* Evaluate profit margins across products and categories.
* Track key business KPIs through an interactive dashboard.

## Key Features
* Revenue, Profit, and Units Sold KPIs
* YoY Growth Analysis using DAX Time Intelligence
* Profit Margin % and Average Order Value (AOV)
* Monthly Sales Trend Analysis
* Category and Product Performance Analysis

## Project Outcome
This project demonstrates how Power BI, and DAX can be combined to transform raw retail transaction data into meaningful business insights. The dashboard provides stakeholders with a centralized view of sales performance, profitability, and growth trends, enabling more informed strategic decisions.
